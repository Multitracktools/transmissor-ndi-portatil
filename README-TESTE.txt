TRANSMISSOR NDI PORTÁTIL — PROTÓTIPO 0.1.0

Este é um protótipo para teste em Windows 10 ou 11 de 64 bits.

COMO TESTAR

1. Extraia todo o conteúdo do ZIP para uma pasta.
2. Não mova apenas o EXE: a DLL que acompanha o programa precisa permanecer na
   mesma pasta.
3. Abra "Transmissor NDI Portatil.exe".
4. Caso o Firewall do Windows pergunte, permita o acesso em redes privadas.
5. Escolha a tela, defina o nome e clique em "Iniciar transmissão".
6. No outro computador, procure a fonte pelo nome informado usando um receptor
   NDI, como o SPresenter, ProPresenter, Studio Monitor ou OBS com DistroAV.

Os dois computadores devem estar na mesma rede local. Para o primeiro teste,
prefira conexão por cabo de rede.

SE OCORRER ALGUM ERRO

Feche o aplicativo e envie o arquivo "transmissor-ndi.log", criado na mesma
pasta do executável. Informe também a versão do Windows, a resolução da tela e
o programa usado para receber o sinal.

LIMITAÇÕES DESTA VERSÃO

- Sem áudio.
- Somente monitor completo.
- Mantém a resolução original da tela.
- Transmite a 30 FPS.
- Ainda não possui assinatura digital.
